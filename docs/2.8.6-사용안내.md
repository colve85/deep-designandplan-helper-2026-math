# 2.8.6 과목 선택 수정

17주 계획 창 맨 위의 **과목 선택 — 중학교·고등학교 수학 전체**에서 과목을 고릅니다. 중학교 수학과 고등학교 수학 20개 과목이 표시됩니다.

**저장된 계획 불러오기**는 이전에 작성한 계획 목록입니다. 전체 과목 목록과 구분됩니다.

과목을 바꾸면 저장 계획을 열거나 새 17주 초안을 만듭니다. 기존 계획의 교사 수정 내용은 유지됩니다. 이전 초안의 문구를 새 생성 방식으로 바꾸려면 JSON 저장으로 백업한 뒤 **현재 과목 17주 초안 다시 만들기**를 실행하세요.

배포 후 버전 2.8.6과 맨 위의 과목 선택 라벨을 확인하세요. 중학교 수학 데이터는 현재 학년별 과목이 아닌 통합 과목군으로 제공됩니다.
