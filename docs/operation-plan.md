# 교수학습 및 평가 운영 계획 사용 안내

운영 계획 화면은 학기별 문서를 별도로 저장합니다. **현재 단원 설계 추가**로 Ⅰ. 교수학습-평가 계획을 작성한 뒤, 지난 학기 최종 PDF가 있으면 **지난 학기 PDF로 채우기**를 사용합니다.

PDF 업로드에는 설정에 저장한 개인 Gemini API 키가 사용됩니다. PDF는 서버에 보관하지 않고 분석 요청에만 전달합니다. 분석 결과는 현재 계획의 나머지 항목에만 병합하며, Ⅰ. 교수학습-평가 계획은 유지합니다. 새 학기의 시기·시수·누계도 자동 복사하지 않습니다.

PDF의 글자가 흐리거나 표가 이미지로만 되어 있으면 일부 항목이 비어 있을 수 있습니다. 이때 **빈 항목 AI 프롬프트**를 눌러 생성된 텍스트를 개인 생성형 AI에 입력하고, 학교 규정과 담당 교사의 판단을 확인한 뒤 붙여 넣습니다. AI가 만든 문장은 교육청·학교의 확정 규정을 대신하지 않습니다.

PDF 분석과 한글 저장에는 인터넷 연결이 필요합니다. API 키가 없으면 PDF 분석을 시작할 수 없으며, 기존 JSON 저장·불러오기와 수동 입력은 계속 사용할 수 있습니다.
