# 중학교 6학기 계획 (2.9.0)

17주 계획 선택은 중학교 6학기와 고등학교 20과목으로 구성됩니다. 학기 배치는 학교의 교육과정 운영에 맞게 조정하는 권장 초안입니다. 공식 성취기준 자체를 변경하지 않습니다.

|학년|1학기|2학기|
|---|---|---|
|1|소인수분해, 정수와 유리수, 문자와 식, 일차방정식, 좌표와 그래프, 정비례·반비례|기본 도형, 작도와 합동, 평면·입체도형, 대푯값, 자료의 정리·상대도수, 통계적 탐구|
|2|순환소수, 식의 계산, 일차부등식, 연립일차방정식, 일차함수|삼각형·사각형의 성질, 닮음, 피타고라스 정리, 경우의 수와 확률|
|3|제곱근과 실수, 근호를 포함한 식, 다항식의 곱셈과 인수분해, 이차방정식·이차함수|삼각비, 원의 성질, 분산·표준편차, 상자그림, 산점도·상관관계|

각 학기는 17주 초안이며 시기·시수·누계는 비워 둡니다. 학년과 학기는 선택한 항목을 기본값으로 채웁니다. 기존 '중학교 수학 전체' 저장 계획은 그대로 불러올 수 있으며, 새 학기 계획은 별도로 생성합니다.

2022 개정 성취기준 데이터 60개를 여섯 학기 중 한 곳씩 배정했습니다. 사용자 참고표에서 빠진 대푯값(1학년 배치), 통계적 탐구, 상자그림도 포함했습니다.

공식 교육과정 안내: https://ncic.re.kr/bbs/ncicnotice/view/845.do
