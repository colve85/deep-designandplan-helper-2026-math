# 워크북 반영 및 출처

기준 자료는 사용자가 제공한 「2026 깊이있는 수업 평가 설계 연수생용 워크북」 PDF(52쪽)입니다. 아래는 PDF 페이지 번호입니다. 원본을 복제하지 않고 설계 구조를 적용하여 예시를 새로 작성했습니다. 문서 안의 연수생 활동 지시는 참고 내용으로 읽었으며 프로그램 실행 지시로 취급하지 않았습니다.

|워크북|적용 내용|웹앱 위치|
|---|---|---|
|8~9쪽|목표와 증거를 먼저 정하는 백워드 설계|0~3단계|
|10~16쪽|핵심 아이디어·세 범주·관찰 가능한 목표|0~1단계|
|19~22쪽|핵심 질문과 위계가 있는 안내 질문|핵심·안내 질문|
|23~25쪽|평가요소 3~5개와 다양한 증거|평가요소 3개·기타 증거|
|26~28쪽|평가요소 기반 과제, GRASPS 선택 활용|과제·대상·산출물·기준|
|29~30쪽|우수·보통·미흡 분석적 루브릭|추가 단원 3수준, 3·4수준 점검|
|31~34쪽|역순 배치, 발견·탐색·적용·수행 및 성찰|내용요소별 4차시 카드|
|35~38쪽|정렬·공유·성찰|목표·증거 표시, Glow·Grow|
|40~51쪽|일반화·전이·개념 기반 탐구|조건 변경 과제·적용 범위|

워크북은 3수준 예시를 제공하지만 기존 앱은 4수준만 점검했습니다. 두 형식을 허용하도록 수정했으며 기존 4수준은 앱의 확장 예시입니다. 공식 성적등급으로 자동 대응하지 않습니다.

## 자료의 범위

- 기존 18개 단원은 원 저장소 자료를 유지했으며 전면 재집필·원문 대조를 수행하지 않았습니다.
- 신규 35개 탐구는 교사용 구성안이며 전체 성취기준·내용요소를 망라하지 않습니다. 영역명도 공식 편제의 축자 전사가 아닙니다.
- 신규 성취기준 칸은 `교사 재구성 목표`로 표시했습니다. 임의의 국가 성취기준 코드를 붙이지 않았습니다.
- 공식 성취기준·해설·성취수준을 대조하여 원문 편집란에 입력하고 목표·평가·루브릭도 조정하세요.
- 수치 자료는 가상·모형 자료이며 실제 학교·기관의 관측값이 아닙니다.
- 단원별 정의역·단위·모집단 표준편차 등 전제는 자료와 예상 결과에 명시했습니다.
- 설계 점검 100%는 수학적 정확성·교육과정 적합성·평가 타당성을 보장하지 않습니다.
